# AI Agents

This project uses one AI “agent” to automate code edits and scaffolding.

**Purpose:**  
Automatically refactor and extend the ShopListGPT Android codebase (Kotlin + XML), as instructed by the user. Seek feedback if you cannot infer user intent.

**Capabilities:**  
- Generate or update Kotlin source files (Activities, Adapters, ViewModels)  
- Create or modify XML layouts, menus, and resource files  
- Produce diffs/patches, full file contents, or standalone snippets  
- Infer existing project structure from prompts/screenshots
- Code changes as required to fulfil user requests.
